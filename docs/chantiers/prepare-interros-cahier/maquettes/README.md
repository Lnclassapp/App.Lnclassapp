# Maquettes de référence

Sources des maquettes de Touré (projet de design, 2026-10-29), reçues en zip le 2026-10-30. **Le design s'applique tel
quel** (memo, règle du chantier). Elles se lisent comme du HTML : styles en ligne, données dans `const N=[…]`, logique
dans `renderVals()`. Elles ne s'ouvrent pas seules (il leur manque `support.js`) : les captures de référence sont dans la
PR du chantier, pas dans le dépôt.

- `prepare-interros-thales.dc.html` : 4 notions × 3 exercices.
- `prepare-devoirs-thales.dc.html` : 3 sujets × 4 exercices ; seuls diffèrent les libellés (« Sujet », « Notions mobilisées »).
